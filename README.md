# Dany — PDI (Plano de Desenvolvimento Individual)

Site pessoal com o meu Plano de Desenvolvimento Individual: quem eu sou, minhas metas atuais, o que estou estudando e os projetos que venho construindo.

🔗 **Site no ar:** `https://seuusuario.github.io/dany-pdi/` *(atualize depois de publicar)*

## ✨ O que tem no site

- **Sobre** — quem sou, de onde sou e minhas metas atuais
- **Plano de estudos** — temas organizados por categoria (Programação, Linguagens, Desenvolvimento pessoal), com filtro e nível de prioridade (alta / média / baixa)
- **Projetos** — cards estilo post com um resumo de cada projeto e link pro repositório/publicação

## 🛠️ Tecnologias

- HTML5
- CSS3 (sem framework — grid, gradientes, animações)
- JavaScript puro (filtro de estudos)
- [Google Fonts](https://fonts.google.com/) — Outfit, Work Sans e JetBrains Mono

## 🚀 Como rodar localmente

Não precisa de instalação nem servidor — é um único arquivo:

1. Baixe o repositório (`git clone` ou zip)
2. Abra o arquivo `index.html` direto no navegador

## 📁 Estrutura

```
dany-pdi/
└── index.html   (HTML + CSS + JS tudo em um arquivo)
```

## 📌 Como atualizar

- **Nova meta:** duplicar um bloco `.goal-card` na seção `#metas`
- **Novo tema de estudo:** duplicar um `.study-item` na seção `#estudos` (categoria em `data-cat`, prioridade na classe `priority`)
- **Novo projeto:** duplicar um `.post-card` na seção `#projetos`
